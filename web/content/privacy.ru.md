# Политика конфиденциальности

**Последнее обновление: март 2025**

Voice Inbox ("мы", "наш" или "приложение") — офлайн-приложение для голосовых заметок. Эта Политика конфиденциальности объясняет, как мы обрабатываем ваши данные при использовании мобильного приложения и опционального веб-API для ИИ-обработки.

## 1. Данные, которые мы обрабатываем

Голосовые записи, транскрипты, сводки, задачи и теги хранятся локально на вашем устройстве. У нас нет доступа к этим данным, если вы не используете функции ИИ, которые отправляют данные на наши серверы.

При использовании функций ИИ (сводки, извлечение задач, Ask AI) приложение отправляет текст транскрипта на наш веб-API по HTTPS. Транскрипт передаётся сторонним провайдерам ИИ (например, OpenRouter, Google, OpenAI) для генерации результатов. Мы не храним транскрипты на наших серверах.

## 2. Наш веб-API

Наш API временно хранит только результат ИИ (сводку, задачи, теги) в хранилище ключ-значение с истечением через 1 час. Через час эти данные автоматически удаляются. Мы никогда не храним транскрипты постоянно.

Мы используем идентификатор устройства (device ID) для ограничения количества бесплатных ИИ-запросов в неделю на устройство. Этот идентификатор используется только для лимитов и не связан с вашей личностью.

## 3. Сторонние провайдеры ИИ

При использовании функций ИИ ваш транскрипт отправляется провайдерам ИИ через [OpenRouter](https://openrouter.ai). Мы применяем **Zero Data Retention (ZDR)** к каждому запросу: маршрутизация идёт только на эндпоинты, где провайдеры не хранят ваши данные. При ZDR провайдеры не сохраняют и не используют транскрипты для обучения. Политика ZDR OpenRouter описана [здесь](https://openrouter.ai/docs/guides/features/zdr).

## 4. Без аккаунтов и входа

Voice Inbox не требует аккаунта или входа. Регистрация пользователей отсутствует, мы не собираем персональные данные (имена, email, пароли).

## 5. Хранение данных

**На устройстве:** записи, транскрипты и контент, созданный ИИ, хранятся до тех пор, пока вы их не удалите или не удалите приложение.

**На наших серверах:** результаты ИИ хранятся до 1 часа, затем автоматически удаляются. Счётчики лимитов по устройствам хранятся до 8 дней, затем сбрасываются.

## 6. Ваши права

Вы можете экспортировать или удалить все свои данные из приложения в любой момент. ИИ-обработка опциональна — вы можете использовать приложение только с офлайн-транскрипцией и никогда не отправлять данные на наши серверы.

## 7. Безопасность

Вся связь с нашим API использует шифрование HTTPS. Приложение поддерживает опциональную блокировку устройства (PIN или биометрия) для защиты доступа к вашим данным.

## 8. Дети

Voice Inbox не предназначен для детей младше 13 лет. Мы не собираем данные детей сознательно.

## 9. Изменения

Мы можем обновлять эту Политику конфиденциальности. Дата «Последнее обновление» в начале отражает изменения. Продолжение использования приложения после изменений означает принятие политики.

## 10. Контакты

По вопросам конфиденциальности свяжитесь с нами по email поддержки, указанному в настройках приложения.
